## Getting Started

### First Launch
When you first open MyTasks, you'll see:
- A summary dashboard with three counters (all showing "0")
- Four tabs: All, Pending, In Progress, Completed
- A floating "+" button in the bottom-right corner

### Main Screen Overview
The home screen is divided into three sections:

1. **Summary Cards** (Top)
   - 🟠 Pending: Tasks you haven't started
   - 🔵 In Progress: Tasks you're working on
   - 🟢 Completed: Tasks you've finished

2. **Filter Tabs** (Middle)
   - All: Shows every task
   - Pending: Only pending tasks
   - In Progress: Only active tasks
   - Completed: Only finished tasks

3. **Task List** (Bottom)
   - Scrollable list of task cards
   - Each card shows title, description, priority, status, and due date

## Managing Tasks

### Creating a New Task

1. Tap the **"+"** floating button
2. Fill in the task details:
   - **Title** (required): Brief name for the task
   - **Description** (optional): More details about the task
   - **Priority**: Choose High, Medium, or Low
   - **Status**: Set to Pending, In Progress, or Completed
3. Tap **"Save Task"**

**Example:**
```
Title: Call dentist for appointment
Description: Schedule cleaning for next month
Priority: Medium
Status: Pending
```

### Viewing Task Details

1. Tap any task card in the list
2. You'll see all task information
3. You can edit any field
4. Tap **"Save Task"** to update
5. Or tap **"Delete Task"** to remove it

### Updating Task Status

To move a task through your workflow:
1. Open the task (tap on it)
2. Change the **Status** dropdown:
   - Pending → In Progress (when you start)
   - In Progress → Completed (when you finish)
3. Tap **"Save Task"**

The summary counters update automatically! ✨

### Deleting a Task

1. Open the task you want to remove
2. Scroll down to find **"Delete Task"** button
3. Tap it to permanently delete the task
4. You'll see a confirmation message

**Note:** Deleted tasks cannot be recovered!

## Using Daily Brief

### What is Daily Brief?

Every evening at **7:00 PM**, MyTasks will remind you to share how your day went. This feature uses smart text analysis to automatically extract tasks from your summary!

### Accessing Daily Brief

**Method 1: From Notification**
- Wait for the 7 PM notification
- Tap the notification
- You'll be taken to the Daily Brief screen

**Method 2: Manual Access**
- Tap the menu icon (⋮) in the top-right corner
- Select **"Daily Brief"**

### Writing Your Brief

Simply write about your day in natural language. The app will look for task-related information.

**Tips for Better Extraction:**
- Use action words: "need to," "must," "should," "have to"
- Mention time frames: "tomorrow," "next week," "Friday"
- Indicate urgency: "urgent," "important," "ASAP"

### Examples

#### Example 1: Basic Tasks
```
Input:
"Had a good meeting today. I need to send the presentation 
to Sarah tomorrow. Should also review the budget report."

Extracted Tasks:
✓ Send the presentation to Sarah
  - Priority: Medium
  - Due: Tomorrow
  
✓ Review the budget report
  - Priority: Medium
  - Due: Not specified
```

#### Example 2: With Priority Keywords
```
Input:
"Busy day! Urgent: need to fix the server issue ASAP. 
Also must complete the client proposal by Friday. 
When possible, update the documentation."

Extracted Tasks:
✓ Fix the server issue
  - Priority: HIGH (keywords: urgent, ASAP)
  - Due: Today
  
✓ Complete the client proposal
  - Priority: HIGH (keyword: must)
  - Due: Friday
  
✓ Update the documentation
  - Priority: LOW (keyword: when possible)
  - Due: Not specified
```

#### Example 3: With Dates
```
Input:
"Project meeting went well. Need to schedule follow-up 
for next Monday. Should prepare slides by next week. 
Also, call the vendor tomorrow about the order."

Extracted Tasks:
✓ Schedule follow-up
  - Priority: Medium
  - Due: Next Monday
  
✓ Prepare slides
  - Priority: Medium
  - Due: Next week
  
✓ Call the vendor about the order
  - Priority: Medium
  - Due: Tomorrow
```

### Understanding Extraction

The app looks for:

**Action Verbs:**
- need to, have to, must, should, will
- plan to, going to, want to
- schedule, meet, call, email, send
- complete, finish, prepare, review, update

**Priority Keywords:**
- **High**: urgent, important, ASAP, critical
- **Medium**: (default if no keyword found)
- **Low**: when possible, sometime, low priority

**Time References:**
- today, tomorrow
- next week, next [day of week]
- this Friday, etc.

### After Submitting

1. Tap **"Submit Brief"**
2. You'll see a confirmation: "Brief submitted! X task(s) extracted."
3. Return to the main screen
4. Your new tasks appear in the list automatically!

## Understanding Priorities

### Priority Levels

Tasks have three priority levels, each with a color:

#### 🔴 High Priority (Red)
**When to use:**
- Urgent deadlines
- Critical issues
- Important meetings
- Time-sensitive tasks

**Examples:**
- Fix production bug
- Submit proposal today
- Attend board meeting

#### 🟠 Medium Priority (Orange)
**When to use:**
- Regular work tasks
- Standard deadlines
- Routine activities
- Most daily tasks

**Examples:**
- Write weekly report
- Review team updates
- Plan next sprint

#### 🟢 Low Priority (Green)
**When to use:**
- Nice-to-have tasks
- Future planning
- Learning activities
- Non-urgent items

**Examples:**
- Read industry article
- Organize files
- Update documentation

### Visual Indicators

Each task card has a **colored bar** on the left side showing its priority. This makes it easy to scan your task list and focus on what matters most!

## Task Status Workflow

### The Three Stages

```
PENDING → IN PROGRESS → COMPLETED
  🟠          🔵            🟢
```

### 1. Pending (Orange) 📋
**Meaning:** Task is created but not started

**When to use:**
- Just created a task
- Planning future work
- Waiting for the right time to start

**What to do:**
- Review task details
- Ensure priority is correct
- Move to "In Progress" when you start working

### 2. In Progress (Blue) ⚙️
**Meaning:** Currently working on this task

**When to use:**
- Started working on the task
- Task is actively being done
- Making progress

**What to do:**
- Focus on completing it
- Update description if needed
- Move to "Completed" when done

### 3. Completed (Green) ✅
**Meaning:** Task is finished

**When to use:**
- Task is fully done
- No more work needed
- Ready to close

**What to do:**
- Celebrate your progress! 🎉
- Review if needed
- Keep for reference or delete

### Best Practice Workflow

1. **Create** tasks as Pending
2. **Start** one task → Move to In Progress
3. **Finish** the task → Move to Completed
4. **Review** completed tasks weekly
5. **Delete** old completed tasks to keep list clean

**Pro Tip:** Try to limit "In Progress" tasks to 3-5 items to maintain focus!

## Tips & Best Practices

### Daily Usage

1. **Morning Review** ☀️
   - Check pending tasks
   - Choose 3-5 to work on today
   - Move them to "In Progress"

2. **Throughout the Day** 💪
   - Update status as you work
   - Add new tasks as they come up
   - Mark completed tasks immediately

3. **Evening Wrap-up** 🌙
   - Use Daily Brief feature
   - Review what you accomplished
   - Plan tomorrow's priorities

### Task Organization

✅ **Do:**
- Write clear, specific titles
- Add context in descriptions
- Set realistic priorities
- Update status regularly
- Use Daily Brief for capture

❌ **Don't:**
- Create vague tasks ("Do stuff")
- Mark everything as High priority
- Let completed tasks pile up
- Forget to update status
- Ignore the daily reminder

### Managing Your Task List

**Weekly Review:**
- Every Friday or Sunday
- Review all pending tasks
- Update priorities
- Delete or archive old completed tasks
- Plan upcoming week

**Monthly Cleanup:**
- Delete outdated tasks
- Review recurring patterns
- Adjust your workflow
- Celebrate achievements

### Daily Brief Best Practices

**Be Natural:**
- Write as if talking to a friend
- Don't worry about perfect grammar
- Include context and emotions
- Mention both wins and tasks

**Be Specific:**
- Include names, dates, and details
- Mention deadlines when known
- State priority when urgent
- Reference projects or contexts

**Be Consistent:**
- Use the 7 PM reminder
- Write daily (even if brief)
- Review extracted tasks
- Adjust manually if needed

### Productivity Tips

1. **Prioritize Ruthlessly**
   - Not everything can be high priority
   - Focus on impact, not just urgency
   - Learn to say no or delegate

2. **Batch Similar Tasks**
   - Group calls together
   - Do emails in blocks
   - Handle related items at once

3. **Use Status Wisely**
   - Limit "In Progress" items
   - Finish before starting new
   - Celebrate completed tasks

4. **Review Regularly**
   - Daily: Today's tasks
   - Weekly: Upcoming tasks
   - Monthly: Overall progress

5. **Stay Flexible**
   - Priorities change
   - Update as needed
   - Don't stress over perfect organization

## Frequently Asked Questions

**Q: Can I change the notification time?**
A: Currently set to 7 PM. Future versions may allow customization.

**Q: What happens if I miss the daily brief?**
A: You can always access it manually from the menu. No tasks are lost!

**Q: Can I edit extracted tasks?**
A: Yes! All extracted tasks can be edited like any other task.

**Q: How accurate is task extraction?**
A: It works best with clear action words and time references. Review and adjust as needed.

**Q: Can I have subtasks?**
A: Not yet, but you can add details in the description field.

**Q: Is my data backed up?**
A: Currently stored locally. Future versions may include cloud sync.

**Q: Can I share tasks with others?**
A: Not in the current version. This is a personal task manager.
